# Exploring the demo

Open the worker dashboard or admin dashboard from the entry page. Use the profile menu to switch roles or reset the fictional dataset.

## Hosting

This copy runs on static hosting at a domain root or a portfolio subdirectory. There is no PHP runtime or database. Serve the folder over HTTP or HTTPS; opening HTML through a file URL does not support the shared navigation fetch.

## Local changes

Records are stored in session storage for the current tab. Reset demo data restores the original fictional records.
