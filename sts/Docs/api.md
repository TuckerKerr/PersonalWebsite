# Demo data layer

STSDemo.request routes the existing page requests to local JavaScript handlers. No PHP request is sent to a server.

## Supported workflows

Equipment returns, four delivery categories, e-waste bins, room checks, field-work review, announcements and reactions, demo user management, semester dates, printer status, imaging and lab station monitoring.

## Integrations

Printer scans and AV controls return simulated results. Lab and imaging dashboards use fictional devices. There are no live device connections. Camera previews stay local; captured images are not uploaded or persisted.
